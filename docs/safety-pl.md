# Bezpieczeństwo

- Nie publikować kluczy, haseł, preferencji ani dokładnych prywatnych lokalizacji.
- Nie łączyć równolegle ogniw o różnym napięciu.
- Li-ion ładować wyłącznie właściwym CC/CV z ochroną; nie ładować poniżej 0°C.
- Chronić PCB, ogniwa i panel przed wodą, kondensacją i upadkiem.
- Nie uznawać RXPS za gwarancję zero packet loss.
- Przed zmianą firmware zachować potwierdzoną drogę rollbacku i nie formatować InternalFS.
